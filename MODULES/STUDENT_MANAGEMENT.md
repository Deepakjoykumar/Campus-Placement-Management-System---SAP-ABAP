# Student Management Module

## Purpose
Maintain student placement profiles.

## Operations
- Create a student profile.
- Read a profile by student ID.
- Update contact, department and CGPA details.
- Delete a profile when permitted.

## ABAP object
`ZSTUDENT_REPORT`

## Database table
`ZSTUDENT_DETAILS`

Use fictional data for testing. Validate identifiers and input values before saving in a production implementation.

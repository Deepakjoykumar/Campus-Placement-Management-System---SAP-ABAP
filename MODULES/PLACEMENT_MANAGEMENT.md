# Placement Management Module

## Purpose
Track student applications and recruitment progress.

## Operations
- Create an application linked to a student and company.
- Read an application by application ID.
- Update recruitment round, status and applied date.
- Delete an application when permitted.
- View applied students and placement status through ALV reports.

## ABAP object
`ZPLACEMENT_REPORT`

## Database table
`ZPLACEMENT_DETAILS`

Suggested status values: Applied, Shortlisted, Selected, Rejected, On Hold.
